# SoundMesh 独立网页版（支持电脑实时音源）

整个应用就一个 `index.html` 文件。放到任意 HTTPS 静态网站托管上就能用，你的电脑不用跑任何服务器。

## 上线方法（二选一，都免费）

**方法 A：GitHub Pages（长期使用推荐）**
1. 登录 GitHub，新建一个仓库，名字随意，比如 `soundmesh`，设为 Public。
2. 在仓库页面点 **Add file → Upload files**，上传 `index.html`，然后点 Commit。
3. 进入仓库的 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main` / `(root)`，保存。
4. 等一两分钟，网址是 `https://你的用户名.github.io/soundmesh/`。

**方法 B：Netlify Drop（最快）**
1. 打开 https://app.netlify.com/drop
2. 把整个文件夹拖进去，马上就会得到一个 `https://xxxx.netlify.app` 网址。注册账号后这个网址才能长期保留。

> 必须用 HTTPS 网址打开。浏览器只在 HTTPS 下才允许共享电脑声音。

## 使用

1. 电脑用 **Chrome 或 Edge** 打开网址，点「创建房间」。
2. 手机扫屏幕上的二维码，点「加入并启用声音」。
3. 在曲目列表里选：
   - **电脑实时音源**：点「开始共享电脑声音」。
     - 放 YouTube Music（网页）：在弹窗里选「标签页」→ 选那个网页 → 打开「同时共享标签页音频」。
     - 放 Spotify 这类桌面软件：选「整个屏幕」→ 打开「同时共享系统音频」。这个选项只有 Windows 上有。
   - **演示曲 / 节拍器**：内置音频，不用文件。
   - **添加音频文件**：文件存在电脑浏览器里，手机会自动从电脑下载。
4. 画布、协同/分工模式、规则、延迟微调和之前的版本一样。

## 让所有设备同时出声：自动校准

控制端右侧有一个「🎯 自动校准」：
1. 「录音设备」选一个有麦克风的设备（这台电脑，或者某台手机），把它放在 👑 听众位。
2. 点「开始校准」，第一次要允许麦克风权限。
3. 各设备会轮流发出“啾”声，每台 3 次。录完后会自动算出每台设备快了还是慢了多少毫秒，填进它的「延迟微调」。不满意的话可以点「撤销」。

蓝牙音箱、不同手机扬声器的固定延迟，都可以这样统一。校准期间音乐会自动静音几秒。

## 安装成 App、防锁屏

- 手机用 Chrome 打开网址，在菜单里选「添加到主屏幕」或「安装应用」，之后就能像 App 一样从桌面打开。
- 播放节点会自动保持屏幕常亮，防止锁屏断音。如果提示「未开启」，点一下页面任意位置。
- 手机切到后台或锁屏后，控制端的设备卡片上会显示红色警告。

## 连接更稳：双通道

- 设备之间配对有两条路：主通道（PeerJS 服务器），和备用通道（Trystero，经过多个公共 Nostr 中继）。
- 手机 6 秒内连不上主通道，会自动改走备用通道，设备卡片上会标出「备用通道」。
- 连上之后，音频都是设备之间直接传的，两条通道的音质和延迟一样。

## 移动音效

在「模式与规则」里选「🌀 移动音效」：
- **环绕**：一个虚拟声源绕着听众转圈。
- **扫射**：虚拟声源从左到右来回移动。
- 离虚拟声源越近的设备越响，画布上紫色的 🔊 就是它现在的位置。
- 可以调速度和强度。设备分散摆在听众四周（前后左右都有）效果最明显。

## 实时拆声部

在实时音源面板勾选「🎚 实时拆声部」，电脑会把正在播放的声音实时拆成 **人声 / 鼓 / 贝斯 / 伴奏** 四条，然后按「声音分工」规则分给各设备：人声给正前方的设备，贝斯给低音设备，其余从左到右分。
这是浏览器里实时运行的简化算法（中置提取 + 谐波/打击分离），分得没有专业 AI 分离那么干净；电脑 CPU 占用大约增加 15~20%。

## 分工检查

在「🎯 校准与检查」里点「开始分工检查」（要先在播放音乐），各设备会轮流单独出声，麦克风录下来分析每台**实际**放的是低音、人声中频、打击还是高频，结果会显示在表格和画布上。

## 歌词

在「🎤 歌词」里搜索歌名和歌手（数据来自免费的 LRCLIB 歌词库），选一个带「⏱ 同步」标记的结果，电脑画布下方和每台手机上都会滚动显示歌词。
- 播放的是自己的文件：歌词自动跟着进度走。
- 实时音源（YouTube 等）：在歌词列表里点一下**正在唱的那一句**来对准，之后会自动滚动。觉得快了或慢了，可以用「提早 / 延后 0.3s」微调，也可以随时再点一句重新对准。

## 注意事项

- **最好所有设备连同一个 Wi-Fi 或手机热点**。设备之间是直连的。跨网络（比如手机用流量）有时会连不上，因为没有中继服务器。
- **实时音源会比电脑晚「缓冲延迟」这么久出声**，默认 0.35 秒，可自动调节。听音乐没影响；看视频时请把电脑本身静音。如果出现卡顿或断续，把缓冲延迟调大。
- 如果共享的是「整个屏幕 + 系统音频」，**不要**同时开「本机也出声」，否则会产生回声。
- 有版权保护的平台（Netflix 等）共享出来可能没有声音。
- 实时音源不能按人声、鼓、贝斯分轨（实时音频本来就没有分轨），但可以按位置分配音量、延迟、左右声道，也可以按频段分工。
- 设备配对用的是 PeerJS 的免费公共信令服务器（0.peerjs.com）。只有建立连接时会用到，音频本身是设备之间直接传的。如果哪天这个服务器不稳定，可以自己架一个 PeerJS 服务器，然后在网址后面加 `?peer=你的服务器:端口`。

## 源码

`source/` 文件夹里是拆开的源码。修改后运行 `python3 build.py`，会重新生成 `index.html`。重新生成需要先 `npm install peerjs@1 qrcode-generator trystero esbuild`，再运行 `npx esbuild vendor/trystero-entry.js --bundle --minify --format=iife --outfile=vendor/trystero.min.js`。
